## GitHub 资料导入与学习复习（2026-10-07）

使用 `启动研究室.bat`，优先启动重新打包的 `dist-ui/InfraResearcher.exe`。进入“资料”→“导入 GitHub 仓库”，填写公开仓库链接，扫描默认分支、固定 commit 和目录；扫描不下载正文。确认文件后才导入。支持首页、末尾斜杠、tree、blob 和 commit 链接，保存固定 GitHub 来源、文件行号与全文索引。可继续部分导入、重试失败文件、补选文件和按新增/修改文件导入新版本；旧版本保留。限制为单文件 1 MB、每批 100 文件 / 15 MB、目录 10,000 文件，不支持截断目录树。

成功导入的资料可用于研究、学习单元和复习卡；模型读取资料须明确开启资料权限，整理资料学习单元另有发送确认。未授权时不提供资料读取工具。来源删除后报告、学习和复习快照保留。仅支持公开仓库，拒绝 Token、Cookie、重定向、敏感文件及疑似凭据；不会执行仓库代码。敏感内容检测为保守规则，不能保证识别所有形式的凭据，导入前请检查自定义选择。

96 项自动化测试通过；真实 Windows WebView2 已验证 `pallets/itsdangerous` 的 docs 与 3 个 Python 源文件选择、导入、搜索行号、固定来源链接和数据库重新打开。打包 EXE 初始化与独立对话重开通过。完整修改清单、迁移、限制和未验证项见 `学习与 GitHub 导入验收.md`。

## 设备与模型（2026-10-07）

侧栏“设备与模型”管理多个命名配置：供应商、Base URL、模型标识、能力标签、默认模型和手机授权。本地 Ollama 使用 `http://127.0.0.1:11434/v1`，其他服务使用 OpenAI Chat Completions 兼容端点。旧连接迁移为默认配置，DPAPI 密文原样迁移；手机授权默认关闭，需在电脑明确开启。配置和任务路由保存在 SQLite，重启保留。

研究 / GitHub 学习、聊天、总结 / 复习制卡 / 报错分析、PPT 内容分别选择主模型和备用模型。周报仍默认本地汇总、无需模型。自动切换默认关闭；开启后只有尚未输出内容且收到明确 HTTP 429 / 500 / 502 / 503 / 504 拒绝时切换一次。取消、网络结果不确定、部分输出不自动重发，保留工作流幂等处理。独立对话和手机可以在每轮选择模型，显式选择时不自动切换。

连接测试检查文字响应；能力测试检查结构化材料提取，研究测试还检查实际工具调用格式，不依赖模型自报能力。记录请求次数、字符数 / 4 估算 token、平均耗时、失败次数及最近错误（不是服务商计费 token）。密钥只在配置保存请求与模型 Authorization 头中使用，不返回初始化、日志、报告、手机接口；服务输出中的当前凭据也会过滤。手机模型列表仅包含电脑授权的名称与能力，不暴露端点或密钥，不能修改配置。最新程序 `dist-models/InfraResearcher.exe`，使用 `启动研究室.bat` 启动。验收详见 `设备与模型验收.md`。

## 复习模块（2026-10-07）

侧栏“复习”服务于研究报告、资料和笔记。可从来源片段手动创建问答题、简答题或选择题，也可在明确勾选“允许将此来源片段发送到所选模型”后生成 1–10 张卡片；AI 返回的答案与摘录会在服务端逐字核对，来源类型、标题、片段位置和 PDF 页码随卡片保存，生成批次必须预览确认后才入库。模型不能凭空生成无来源事实。

卡片保存问题、答案、来源快照、标签、项目、难度和下次复习时间。提供“不会、困难、认识、熟练”四档自评间隔：10 分钟、至少 1 天、首次 1 天、首次 4 天，后续按已有间隔递增并设一年上限。每日显示到期数量和用户完成次数，完成提示明确说明系统没有证明掌握；重复反馈会被版本号拒绝。支持按项目、标签、来源筛选，答案页可回到报告、资料原文或笔记，PDF 保留页码。复习表和事件表独立保存，重启后继续。手机端不开放复习接口。

验收与限制见 `复习模块验收.md`。当前算法是可解释的本地最小间隔重复，不是成熟记忆模型；卡片相关性、选择题干扰项和来源本身的正确性需要用户检查。

## 任务与自动化模块（2026-10-07）

侧栏“任务与自动化”保存通用任务：标题、描述、标签、优先级、截止时间、状态、资料/报告关联和一次性、每日、每周、自定义周期。列表、按月日历、逾期和完成记录共用本地 SQLite；周期任务完成时只推进下一次截止时间，并保留本次完成事件。

快捷工作流先创建不可变输入快照，再由用户手动运行：周报总结按起止时间在本地汇总报告、最近编辑笔记、任务事件和学习进度事件；报错修复与 PPT 内容制作在明确授权后把日志和选定来源发送给模型；闲时任务从未完成学习任务生成 15–30 分钟阅读切片。每次运行保存来源、状态、取消请求、错误日志、尝试次数和输出。周报成功后原子写入一份研究报告；相同执行标识不会再次创建报告。

定时计划和全局开关默认关闭。开启后仅在研究室运行时按计划执行，程序关闭期间不补跑全部错过的周期；模型请求已发出但结果不确定时标为“请求结果不确定”，不会自动重发。模型收到响应但本地发布失败时可以重试同一次响应，不会重复发送模型请求。手机端不开放任务、自动化和工作流接口。验收见 `任务与自动化验收.md`。

## 资料模块（2026-10-07）

侧栏“资料”保存本机资料库：可导入 TXT、Markdown、PDF、常见代码文件或文件夹批次。SQLite 记录文件名、绝对路径、类型、字节数、SHA-256、导入时间、标签、所属项目、失败原因和分块；同内容重复导入只返回已有记录。PDF 按页保存提取文字，搜索结果和预览显示实际页码。搜索优先使用 SQLite FTS5，运行环境不支持时自动使用本地 `instr` 子串检索回退；`Library` 的 `RetrievalBackend` 接口为未来本地向量索引预留，当前不联网。

导入失败会保留失败记录和原因，支持重试；删除资料会通过 SQLite 外键级联删除页、分块、标签及全文索引，原始文件不会被删除。预览读取导入时的文本快照，因此原文件后来移动或删除不影响已保存资料。

研究页、GitHub 学习页和报告追问各自有“允许研究 Agent 检索资料库”复选框，默认关闭。关闭时模型没有 `search_materials` 工具，也不会收到资料片段；追问会从上下文中移除此前资料库读取的消息。开启后工具只查询已导入分块，返回片段、来源路径和 PDF 页码并写入报告证据。手机端保持原有研究/聊天权限，不会默认暴露资料库接口。

独立原生窗口，支持项目分析、个人背景、源码阅读证据、追问、历史记录与 Markdown 导出。研究成功完成后自动保存到本机 SQLite 数据库，正文、证据、时间和追问可在“研究历史”重新打开；关闭或重启后保留，手机可读取同一份记录。失败/取消的未完成输出不保存为正式报告。

## 笔记模块（2026-10-07）

侧栏“笔记”支持 Markdown 编辑和约 1 秒自动保存、删除与恢复、标题、标签、文件夹、置顶与最近编辑排序。可关联资料、研究报告、GitHub 仓库及学习任务，并在资料和报告中查看引用它的笔记。保留当前版本和最近 10 个历史版本，恢复包括元数据和关联关系。单篇导出 Markdown，桌面文件夹导出生成多个独立 .md 文件。笔记使用独立表，不改写研究报告。

研究、GitHub 学习和追问的“读取笔记”权限分别默认关闭。开启后才提供 search_notes 工具，命中内容会发到所选模型并记入证据；关闭后追问从未读笔记的上下文继续。手机界面未开放笔记权限。使用与验收见 `笔记模块验收.md`。

## 独立对话与手机连接（当前版本）

最新版本 `dist-tasks/InfraResearcher.exe`。关闭旧窗口后，双击 `启动研究室.bat`。点击左侧“对话 Agent”会打开白色简约的独立原生窗口；再次点击复用该窗口，关闭后可重开。主研究室关闭时一起退出。窗口共用同一个服务、数据库和模型配置，支持新建、搜索、改名、流式回复、停止、附加材料、导出与角色设置。角色变更只用于新会话。

“关联研究室”显示背景、当前角色、研究报告和学习进度。查看记录不会自动发给模型；开启输入框旁的“读取研究室记录”后，模型可按需检索报告正文和学习进度，实际工具记录与证据显示在回复下方。读取受原有工具权限和上下文预算限制，不访问其他应用或任意电脑文件。

手机可使用 Android APK 或自适应网页：

1. 电脑与手机连接同一 Wi-Fi，电脑研究室保持开启。
2. 电脑侧栏“手机连接”→“开启手机连接”，显示一个或多个局域网地址和六位配对码。
3. 手机浏览器输入电脑 Wi-Fi 网卡对应的地址，例如 `http://192.168.1.5:端口/`，输入配对码。
4. 手机可聊天、查看会话/报告/学习进度、启动和停止研究。任务使用电脑已配置的模型；电脑主界面定期同步新报告和运行中研究。
5. “关闭并撤销访问”立即撤销全部手机会话并关闭监听；退出应用也会关闭。下次启动默认关闭。

配对码十分钟有效，每个来源十分钟最多五次失败；设备会话最多十二小时，并可由电脑关闭撤销。API Key 不返回手机，模型设置和其他桌面管理操作不开放给手机。局域网使用 HTTP，请使用信任的 Wi-Fi；此版没有外网连接、远程桌面或鼠标键盘控制。Android APK 在 `dist-android/InfraResearcher-Android.apk`，支持 Android 6.0 及以上，使用系统 WebView。将 APK 传到手机并安装，打开后输入电脑显示的局域网地址，再在配对页输入六位码。保存的是地址，电脑重启端口可能变化，需重新填写。安装包为本地开发签名；未上架，未在实体手机运行验收。手机或电脑休眠、Wi-Fi 客户端隔离、防火墙可能阻止连接；Windows 如询问网络权限，请只允许专用网络，应用不自动更改防火墙。此版没有二维码。

本机浏览器小屏验收使用测试夹具，未在实体手机与第二台设备间验证；详情见 `验证记录.md`。

## 手腕联动、Wink 微笑、对话搜索与 GitHub 热点（当前版本）

前臂动作新增手腕延迟跟随与回落放松，手掌不再全程与前臂保持同一角度；水纹接触点采用前臂和手腕的组合位置，组合角度受原有安全范围限制。Wink 新增闭口微笑，眼睛先动、嘴角柔和跟随，结束后平滑恢复，保留暂停与入场抑制。仍是当前原画的二维形变，未制作全身骨骼或独立手指动作。实际采样 Character-flex-preview.gif、Wink-smile-preview.jpg。

独立 Agent 对话与手机页的搜索框支持会话标题、用户/助手消息和附加材料，不区分拉丁字母大小写，显示匹配片段，点击打开会话并定位第一条匹配消息；本机执行，不调用模型。最多显示 100 个会话，按最近更新排列；已删除会话不在搜索结果中，恢复后重新可搜。空词恢复会话列表，无匹配显示说明。正文定位以第一处命中为准，不提供全文高亮或上一条/下一条导航。

侧栏新增“GitHub 热点”：实际 GitHub Trending 日榜、周榜、月榜，显示仓库简介、语言、总星标和周期新增星标，并可加入学习/研究。打开榜单时检查更新；页面停留且可见期间每 15 分钟检查，手动刷新可提前更新（30 秒请求冷却）。缓存保存到本机，离线/解析失败保留上次榜单与原始时间。日/周/月是官方时间窗口，不是历史归档，应用关闭时不更新，也不产生自动通知。榜单是公开全站项目，尚无 AI Infra 专项筛选，热门程度不代表学习价值。

## 逐笔描边入场（2026-10-06）

“原画蓝光描边”沿原画轮廓逐段绘制。约前六秒从头部向发丝、衣服、裙摆和身体延伸，最后淡入原画与主页，总时长约 8.2 秒。描边提亮并减少细碎纹理，背景加入低亮度蓝色光晕和细小光点；使用原画构图，窗口变化后按同一图片坐标缩放。“跳过入场”可立即结束。旧参考视频选项保留。

Wink 闭眼线向上并略向内调整，避免落在脸颊外侧；笑嘴继续使用原画嘴线形变，减少外侧提拉并保留符合脸部倾角的弧度。实机 Canvas 样本见 Entry-WebView-2.3.png、Entry-WebView-4.2.png 和 Wink-WebView-canvas.png；是隔离 WebView 中的实际绘制输出，未包含完整窗口 UI。

## 面部表情修复（2026-10-06）

替换以前分别覆盖眼睛与嘴部的处理方式。眼睛与嘴部共用原画坐标和同一张完整面部纹理；眼睑保留原睫毛的颜色和粗细变化，闭合时遮盖虹膜，保留周围蓝色头发。嘴部不再重画弧线，改为对原嘴线及附近光影进行局部形变，嘴部沿脸的倾斜方向形成浅笑，外侧嘴角最多上移约 2.8 原图像素，唇中段小幅下弯。Wink 保留另一只眼睛，微笑柔和跟随并恢复。

已检查原图、半闭合、闭合及真实 WebView 的 Wink 峰值，运行面部边界/虹膜残留/嘴角幅度检查、动作中断与入场生命周期检查。仍为二维局部形变，闭眼区域的皮肤需根据原画采样补全，未制作专业面部动画模型；主观自然度由实际效果评估。放大对比 `Face-source-comparison.png` 是素材合成预览，不能当作实机截图。

## 协调动作与穿模修复（当前版本）

抬手/拨水改为沿尾鳍与裙边之间的水面空隙运动，100% 强度限制在约 -9.2°～13.2°，低强度按比例缩放。关节上移至袖子上端，固定连接处，袖口与手掌保持整块旋转；修补背景时恢复上端袖子，避免被扩大擦除范围留下缺口。手部切换使用更慢的阻尼跟随，水光中心使用同一个关节/角度。保留慢眨眼、Wink、暂停与入场后的渐进接续。

81 个最大强度姿态与保守尾鳍/裙边轮廓检查未重叠，最小余量 9 个原图像素；这是该原画的二维几何验收，不是三维碰撞系统或全身骨骼动画。浏览器实际正反拨水与抬手切换采样见 Character-natural-preview.gif，原位置水面修补仍有细节损失。

## 主页动作、入场与对话删除（当前版本）

修复手臂回到原位时切换原图造成的重影：所有角度使用同一底图与透明手臂合成，清理原位置轮廓残留；底图改为无损 PNG，保留平滑关节与连续位置/速度。慢眨眼约 0.72 秒，新增约 1.05 秒单眼 Wink，睁眼较慢，重复触发平滑接续。眼睑是原画程序近似，仍可能有风格差异。

原画描边入场以实际绘制进度结束，不依赖可暂停的主页时钟；暂停时也可完成入场，恢复后逐步开启运动。入场抑制角色动作，结束淡入界面；跳过/重复播放取消旧回调。原画描边仅在原画和角色水流模式可用，避免切到其他背景时构图不匹配。

独立 Agent 对话窗口和手机端可“删除对话”，确认显示会话名；正在回复时禁止删除。会话移到“已删除”，可恢复，重启保留。删除只隐藏对话，不永久清除数据，不影响研究报告。多窗口会同步移除已删会话，原有隐藏的旧聊天页未新增删除入口。

## 对话 Agent、视频入场与角色动作库

此前聊天版为 `dist-chat/InfraResearcher.exe`。左侧“对话 Agent”提供会话列表、多轮流式回复、停止、改名、复制与 Markdown 导出，沿用现有模型连接。模型按需调用公开 GitHub 搜索、固定 commit 仓库阅读等只读工具，工具记录与实际证据显示在消息下方。

## 开始使用

1. 双击 `启动研究室.bat`，优先启动细化修复版 `dist-detail/InfraResearcher.exe`；打包版无需安装 Python。
2. 打开左侧“模型连接”，填写 OpenAI 兼容的 Base URL、模型名与 API Key，点击测试连接并保存。测试会产生一次实际模型请求；服务费用由你所选服务商决定。
3. 可选：在“我的背景”填写相关基础、硬件与目标。
4. 输入公开 GitHub 仓库首页链接、文章链接，或粘贴 / 导入 Markdown、文本、源码、PDF。
5. 点击“开始研究”。完成后可在“阅读证据”查看实际读到的源码片段；报告自动保存，也可导出 Markdown、继续追问。

远程接口使用 HTTPS。本机 Ollama 可填 `http://127.0.0.1:11434/v1`，模型名填写本机已安装的模型，密钥可留空。支持 Chat Completions 的模型可生成报告；按需读源码另需模型支持工具调用。模型不支持工具时，在设置里关闭“允许模型按需读取仓库源码”。

## 分析范围

- GitHub：固定默认分支的 commit，先读取目录和根 README，再通过模型工具调用按需阅读最多 10 个文件片段。每片段最多 250 行，源码材料总预算约 75,000 字符。读取失败会交给模型标明限制，不假定已审阅整个仓库。
- 当前只支持公开仓库首页链接。不支持私有仓库认证，不克隆或执行仓库，不运行性能实验。
- 为分析作者制作过程，模型可读取固定 commit 之前最近 10 条提交摘要（可按已知文件路径筛选），以及当前仓库已知编号的 Issue/PR 正文与前 10 条评论。历史与讨论工具合计最多 4 次；不读取提交 diff、不搜索全站讨论或完整开发历史。当前讨论可能晚于固定 commit，报告必须说明此限制。没有证据时只提供推断或建议路线，不能伪造作者经历。
- 文章：提取网页可见文本，最多 25,000 字符；需要登录或由脚本生成的正文可能无法取得，可改为粘贴文本。
- PDF：导入本地文件，提取前 40 页 / 约 35,000 字符，不含图片或 OCR。扫描件请先自行提取正文。
- 一次研究最多 8 轮模型调用。较大项目适合按机制分次研究，不保证所有路径都已阅读。

模型报告仍需你检查关键结论；证据面板与固定 commit 链接可以帮助复核。所有未运行实验只能列为计划。

## 数据与密钥
